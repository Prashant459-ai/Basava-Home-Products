# 🏠 Basava Home Products - Premium Natural Oils & Products

## Project Description

**Basava Home Products** is a modern, responsive landing page and product showcase website designed for a company specializing in high-quality, pure, and traditional **natural oils and coconut powder**.

This repository contains the front-end code for the website, which is built to provide an engaging user experience, showcase premium products, and facilitate direct ordering via WhatsApp.

## ✨ Features

The website incorporates various modern design and functional features:

* **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
* **Dynamic UX:** Features a **pre-loading screen**, a subtle **floating particles background**, and a sticky, shrinking header on scroll.
* **Scroll Animations:** Uses the **Scroll Reveal** effect to introduce content sections and products dynamically.
* **Animated Stats:** Includes an animated counter section to highlight key business metrics (e.g., % Pure & Natural, Years Experience).
* **Product Showcase:**
    * **Filterable Grid:** Products can be filtered by category (All, Oils, Powder).
    * **Details Modal:** Clicking "Details" on a product opens a modal with a detailed description.
    * **WhatsApp Integration:** Direct links on every product card for easy ordering or inquiry via WhatsApp.
* **Contact Form:** A stylized contact form for user inquiries (submission is handled by JavaScript for a local alert/confirmation).
* **Clean Code Separation:** The project is structured using separate files for HTML, CSS, and JavaScript for maintainability.
